# 费曼学习法

**英文备注：** Feynman Learning  
**技能标识：** `feiman-learning`

## 功能

帮助你通过自己的话解释概念、发现理解漏洞、针对性追问、纠错和迁移测试，判断自己是否真正掌握知识。支持从头学习和闭卷检验两种模式，也可按需生成 Markdown 学习记录。

## 在 Codex 网页版使用

打开本仓库的 Codex 任务，调用 `$feiman-learning`，然后说出你要学习或检验的概念。例如：

> $feiman-learning 我想学习亚马逊广告的 ACOS。请从头教我，用中文解释，每轮只问我一个问题。

## 文件结构

- `SKILL.md`：技能工作流程和触发说明。
- `references/learning-modes.md`：学习模式与检验模式。
- `references/questioning-and-evaluation.md`：追问、纠错和掌握度评估。
- `references/obsidian-guide.md`：可选的 Obsidian 知识库指南。
- `references/template.md`：费曼学习记录模板。
- `references/example.md`：完整学习记录示例。
