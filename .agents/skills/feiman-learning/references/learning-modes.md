# 两种学习模式

根据用户是否已经具备基础选择模式。模式不是固定标签；学习过程中可以随时从学习模式切换到检验模式。

## 检验模式

适合已经上过课、读过资料、准备考试，或怀疑自己“好像懂了但说不清”的用户。

### 流程

1. 明确概念范围和实际目标。
2. 请用户闭卷完成第一次讲解，不查资料、不看笔记。
3. 从讲解中找出最关键的事实、机制、术语或边界漏洞。
4. 每轮提出一个高价值问题。
5. 对回答进行事实与逻辑判断，必要时纠错。
6. 请用户重新讲解被修正的部分。
7. 使用反例、对比或新情境进行迁移测试。
8. 总结掌握情况并按需归档。

### 首次提示示例

> 先不要看资料。请你像讲给一个没有背景知识的人一样，说说它是什么、为什么会这样，并举一个例子。

如果用户只能背诵定义，不要否定定义本身，而是继续问定义中某个关键词、因果机制或具体例子。

## 学习模式

适合第一次接触、基础不足，或者明确要求从头讲解的用户。

### 最小必要讲解

先提供足以开始复述的内容，而不是一次给出完整教科书：

1. 一句话说明核心概念；
2. 解释一个关键机制；
3. 给出一个准确的具体例子；
4. 必要时说明一个常见误区。

讲解后请用户脱离刚才的原句，用自己的表达复述。随后进入与检验模式相同的追问、纠错和迁移测试。

### 首次提示示例

> 我先给你一块最小拼图，够我们开始练习。听完后请不要照抄，而是用自己的话重新讲给我听。

### 控制信息量

- 用户完全陌生时，一次只教一个知识块。
- 用户复述正确后再加入下一层细节。
- 用户要求完整解释时可以直接提供，但解释后仍应通过复述或应用检查是否吸收。
- 不把“不知道”视为失败；它只是说明当前需要先教学。

## 模式切换

- 学习模式中，用户能稳定复述后，切换到检验模式。
- 检验模式中发现基础缺口时，短暂切换到学习模式补齐，再返回检验。
- 用户可以随时要求更多讲解、更少追问、加快节奏或结束。
